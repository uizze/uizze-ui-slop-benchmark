02

The reproducibility contract

  1. Use the checked-in prompt and starter state unchanged.
  2. Give every candidate the same tools, network access, and implementation window.
  3. Record candidate version, commit, elapsed time, evaluator, and viewport checks.
  4. Award only binary scores with evidence another person can inspect.
  5. Treat any prompt, starter, or rubric change as a new benchmark version.
